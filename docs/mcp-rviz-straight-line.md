# RViz 点击式直线绘制与细红线

日期：2026-09-24。

## 使用

工具栏新增 **直线绘制（L）**，原有自由手绘（连续画线 D）和航点编辑（E）保留。

- 空草稿：点击起点；移动鼠标时显示起点到鼠标的直线预览以及本段距离、路线总长；再点击固定终点。
- 后端确认后自动从刚固定的终点开始预览下一段，继续移动／点击即可接段。
- Esc 或右键结束当前未提交的预览，已经确认的线段保留。撤销／重做以已确认的编辑为单位。
- 从已有草稿重新开始时，以现有路线末点为起点；首次点击进入续画预览，再点击确认新终点，不会在路线中创建断开的独立线段。
- 距离是地图 XY 平面的折线长度，单位米。预览中的顶点数包含尚未确认的末端点。
- 同一点重复点击、长度小于 1 cm 的线段不提交。原有版本冲突、锁定、最多 2000 顶点及 200 m 路线限制保持不变。
- 滚轮缩放仍可用；直线悬停预览期间也可用中键平移。

## 样式

所有绘制预览线改为红色、约 1 个逻辑像素的细线。已提交手绘路线的 RViz Path 显示从粗黄色 Billboard 改为红色 Lines（普通细线）；没有修改执行路径的几何或采样间距。顶点也改为较小的红点。

新增距离栏固定高度，避免实时文字行数改变后导致绘图区布局跳动。

## 修正投影

测试中发现原代码用 RenderPanel QWidget 的宽高归一化来自 RenderWindow 的鼠标坐标，包含了边距差异，也未匹配 ViewportMouseEvent 的设备像素缩放。现在使用实际 RenderWindow 尺寸及事件的设备像素倍率，使鼠标落点与渲染区域一致。

首次探针已成功固定两条直线，但最后预览被起点连接距离限制拒绝；随后修正上述投影，并稳定距离栏布局、让夹具重新读取绘图区中心，正式通过。没有放宽 1 m 起点连接限制来绕过测试。

## 验证

在 Humble 主机编译并安装 agt_rviz_route_tools、agt_rviz_patrol。

- C++ 插件／几何测试：2 项通过；插件测试新增第三个直线工具加载及快捷键检查。
- Python 后端相关回归：37 项通过。
- 独立 domain 103 / 显示 :194 的真实 RViz GUI 测试通过。
- 使用 QT_SCALE_FACTOR=2 的独立 domain 104 / 显示 :195 也通过同一套交互测试；这是软件渲染测试环境，不等同于现场显示器的人手体验验收。

新增 GUI 断言：

1. 同一位置重复点击不提交零长度线段；
2. 鼠标故意来回晃动，悬停阶段后端仍无已提交顶点；
3. 普通显示下，移动至 80 像素外显示本段 10.00 m；点击后后端只有两个顶点；
4. 相同屏幕 y 的端点在地图坐标中形成水平直线，相同 x 的下一段形成竖直线；
5. 第二段接上后仅有三个顶点，前段端点不变；
6. 绘图区中心点击落在视图中心坐标附近；
7. Esc 保留已确认两段、不提交悬停候选段；撤销／重做与离线预览通过；
8. 三种工具均能滚轮缩放，原有自由手绘、航点编辑、中键平移及离线执行禁用仍通过。

没有运行车辆、没有修改碰撞门控或发送真实运动目标，没有提交或推送。

## 加载与证据

运行中的 RViz 不能热加载新的 C++ 插件。完整重启原离线 launch 可同时加载新工具、细红线配置和红色顶点；重启后端会清空内存中的草稿。只关闭／重开 RViz 并保留同 domain 的原后端，可以保留草稿并使用新工具和细红线，但后端提供的顶点颜色／大小仍为旧版本，直到后端重启。

不要用旧窗口覆盖安装目录中的新版默认配置；不要只启动 RViz 而忘记地图和工作台后端。

仓库变更：route_tools.cpp/.hpp、plugins.xml、原生插件／GUI 测试、两份 RViz 配置和 workbench.py 的顶点显示样式。
